# BUG-22: Unify DECID and DA1

## Problem

DanTerm recognizes `ESC Z` as a single-byte escape action but does not reply.
The existing DA1 spellings, `CSI c` and `CSI 0 c`, reply with
`ESC [ ? 1 ; 2 c`. DECID is the obsolete spelling of that same primary device
attributes query, so a program that uses it waits for a reply that never comes.

## Decision

Treat exact `ESC Z` and the accepted DA1 spellings as syntax for one semantic
query. They share one responder and therefore cannot acquire different device
identities.

Syntax validation remains with each dispatcher. Escape sequences with
intermediates and CSI forms with unsupported parameters remain silent. The
change is confined to terminal-core dispatch; it adds no public API.

## Invariants

- `ESC Z`, `CSI c`, and `CSI 0 c` produce the same exact 7-bit reply:
  `ESC [ ? 1 ; 2 c`.
- DECID changes only the ordered reply channel. It does not change visible or
  semantic terminal state.
- Input chunk boundaries do not change DECID behavior.
- Unsupported variants remain silent.

## Proof obligations

- First add a behavioral test that feeds `ESC Z`, observes no reply on the
  current tree, and expects the established primary device attributes reply.
- Prove that DECID and both accepted DA1 spellings emit the same reply in stream
  order.
- Prove that DECID preserves pending wrap and an open grapheme cluster after its
  reply is drained.
- Prove that splitting the DECID bytes at every input boundary does not change
  terminal state or output.
- Prove that an intermediate-bearing form such as `ESC SP Z` remains silent and
  leaves terminal state bit-identical.
- Run the targeted `TerminalQueryTests`, then the escalated `just test` gate.

## Completion

- After the implementation lands, mark BUG-22 done in the construction audit
  with the implementation commit id.

## Non-goals

- Do not implement ECMA-48 SCI semantics, 8-bit DECID/C1 input, DA2, or 8-bit
  replies.
- Do not introduce a general query abstraction or add PTY, CLI, capability-doc,
  or design-register changes. Existing coverage already proves reply transport.

## Implementation discretion

- The shared responder's internal name and placement are left to implementation.
