# Contributing

Thanks for your interest in DanTerm!

This project doesn't accept pull requests -- all development happens
through the maintainer's own pipeline. The best way to contribute is by
[opening an issue](../../issues/new):

- **Bug reports** -- steps to reproduce, expected vs. actual behavior,
  and your macOS version all help a lot
- **Feature requests** -- describe the problem you're trying to solve
- **Questions and feedback** -- always welcome

Issues are read and appreciated. Thanks for taking the time.
