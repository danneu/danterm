# Pinned esctest2 cases selected for stateful behavior DanTerm advertises.
#
# Selection rule. The runner requires selected == expected, failed == 0, and
# knownBugs == 0, and esctest counts an InsufficientVTLevel skip as a known bug.
# The runner also fixes --max-vt-level=3. So a case earns a place here only when
# every assertion it makes is observable through a reply DanTerm actually sends
# -- CPR/DECXCPR, DA1, DECRQM, or DECRQSS -- and it carries no @vtLevel(4|5),
# @optionRequired, or xterm @knownBug decorator. Any case that reads screen
# contents is excluded: esctest reads them with DECRQCRA, which DanTerm does not
# implement, and AssertScreenCharsInRectEqual demands VT level 4.
