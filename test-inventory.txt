# DanTerm test migration parity inventory (Phase 1 baseline).
#
# For each tests/<File>.swift in the legacy harness, captures:
#   - per-idiom failure-site counts (expect( + expectEqual( + throw TestFailure)
#   - the display name of every test("...") declaration
#   - migration status (PENDING | MIGRATED <commit-sha>)
#
# Phase 2 per-wave gates (each migrated file):
#   1. NAME parity: every baseline name maps to a migrated @Test("...") name.
#   2. ASSERTION parity: old TOTAL == new TOTAL where
#        old TOTAL = expect( + expectEqual( + throw TestFailure
#        new TOTAL = #expect( + expectNoDifference( + #require( + Issue.record(
#      Two kinds of delta are allowed when logged: an intentional
#      @Test(arguments:) collapse (assert element count == old loop iteration count)
#      and an intentional assertion strengthening (e.g. CheckpointTests' on-disk
#      temp-path checks). Any unexplained inequality fails the wave.
#   3. STYLE: every migrated test carries the Intent/Why/Scenario preamble.
#
# Regenerate the per-file baseline counts with:
#   for f in tests/*Tests.swift; do
#       e=$(grep -cE 'expect\(' "$f")
#       eq=$(grep -cE 'expectEqual\(' "$f")
#       tf=$(grep -cE 'throw TestFailure' "$f")
#       echo "$(basename "$f" .swift)  expect=$e expectEqual=$eq throwTF=$tf TOTAL=$((e+eq+tf))"
#   done
